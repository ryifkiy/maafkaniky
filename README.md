# Website permintaan maaf untuk Rizka

Website statis bertema kuning yang dibuat berdasarkan alur referensi: pembuka amplop, menu kejutan, galeri foto, refleksi hal-hal kecil, video YouTube, dan surat permintaan maaf.

## Menambahkan foto

Masukkan enam foto ke folder `assets/photos` dengan nama persis:

- `foto-1.jpg`
- `foto-2.jpg`
- `foto-3.jpg`
- `foto-4.jpg`
- `foto-5.jpg`
- `foto-6.jpg`

Jika foto belum ditambahkan, website otomatis menampilkan placeholder bebek kuning. Format `.jpg` paling mudah digunakan. Sebaiknya gunakan foto vertikal atau persegi dan kompres ukurannya agar masing-masing di bawah 1 MB.

## Menjalankan

Buka `index.html` langsung di browser, atau jalankan server lokal dari folder proyek agar semua fitur browser bekerja konsisten.

Video yang dipasang adalah `LANY - Alonica (Official Music Video)` dari kanal resmi LANY di YouTube.
